# 現在と目標、結果更新、身体作用を分けて調べる

公開されたショウジョウバエ研究から、未知の状況で既知の動作を選び、結果を次の選択へ戻す仕組みを調べた。対象は文献、公開記録の再解析、MaleCNS v1.0の限定接続取得、公開模型の独立計算である。

得られたのは、現在と目標を別に保持する計算、手掛かり別の応答更新、身体状態に依存する運動出力を比較する材料である。右中脚では筋・運動ニューロン集合から上流の6候補まで番号を絞れた。一方、その6候補の自然活動と経験による選択変更を同一個体・同一試行で結ぶ記録は得られていない。配線、Ca蛍光、発火、介入、行動、模型内の量は、それぞれ測定の意味を保って読む。

### 1. 現在と目標の関係から、出力を変える

景色を±90°動かした公開記録43本・430跳躍を扱った。跳躍前60秒に方位が安定し、歩行が10秒以上あり、可視・信号品質条件を満たす部分では、活動の山の早期変化はEPGで92.8°、FC2で17.7°だった。前者は71試行・9個体、後者は68試行・13個体である。現在方位へ追従する表現と、直前の方位を比較的保つ表現を分ける材料になる。ただし、この前状態条件は初回結果の後に加えた探索的比較であり、同一個体内のEPG→FC2伝播を測ったものではない。[Piresら](https://doi.org/10.1038/s41586-023-07006-3)

保持が行動を保証するわけでもない。FC2の早期変化が90°追従より0°保持に近い55試行のうち、31試行では5〜10秒後に元方位の30°以内へ戻らなかった。初期状態、活動表現、実際の旋回を分けて評価する必要がある。[前状態ごとの集計](../data/navigation/prestate_summary.csv)

PFL3の電気記録由来15細胞・396区画値では、細胞を一つずつ外す予測比較を行った。細胞を等重みとする平均二乗誤差の平方根は、方位と目標を非線形に合わせたsoftplus式11.80 Hz、任意の方位項と目標項を足す式13.64 Hz、方位だけを非線形化した式15.17 Hzだった。別の交互作用式は12.15 Hzで、その式との優劣は不確実である。特定の非線形式を唯一の仕組みとはしない。[細胞別予測誤差](../data/navigation/pfl3_cell_prediction_errors.csv)

公開模型の計算は、生体測定と分けて実施した。Westeindeの既存計算では3目標×3利得×361方位×2条件、計6,498条件の有限出力と方向を確認したが、条件ごとの正規化があるため絶対利得の生理較正にはならない。Danの公開模型v1.1のPython独立翻訳では128訓練・160凍結評価を行い、安全域選好PIの平均改善は両更新+0.4103、目標だけ+0.1213、地図だけ−0.0059だった。両更新が常に必須とは言えず、現在方位、旋回、安全・危険の意味は模型に与えている。MATLAB原実行の完全再現や未知操作の意味獲得ではない。[Westeindeら](https://doi.org/10.1038/s41586-024-07039-2)、[Danら](https://doi.org/10.1016/j.neuron.2024.04.036)

### 2. 結果の変化を、手掛かり別の応答へ戻す

HuangのPPL1-α3は、12個体×2匂い×4時点の96記録を揃え、著者検出済みの活動電位を再計数した。匂い[5,10)秒の毎秒発火数から基線[2,5)秒の毎秒発火数を引くと、出版社数表の96値に一致した。旧解析の[0,5)秒基線とは分ける。

CS+−CS−応答差の学習前からの変化Dは、前半訓練後+8.9333 Hz、終了5分後+7.6944 Hz、1時間後+2.5056 Hzだった。1時間後の95%再標本化区間は[−1.028, 6.333] Hzで零を跨ぐ。Fly03では学習前と1時間後の二匂いの生理配列が重複しており、除外感度でも区間は零を跨いだ。完全な持続・消失、独立した12個体の全時点追跡成功とは言わない。[Huangら](https://doi.org/10.1038/s41586-024-07819-w)、[訂正後の集計と感度](../data/learning/huang_corrected_summary.json)

McCurdyの反転学習では、反転を1対経験した後の旧CS+応答変化はPAM-β′2aで+5.731、MBON-γ2α′1で+3.235、MBON-γ5β′2aで−2.114だった。単位は原表のΔR/R差で、型間は別個体群である。後続の113個体行の比較では、二つの匂いへ同量が加わるだけの説明を制約したが、共通倍率や感覚利得の変更まで排除していない。[McCurdyら](https://doi.org/10.1038/s41467-021-21388-w)

この資料では19値窓で452比較を再構成でき、PAM無電撃対照は全12行を使うと公表統計を再現した。n=11の表記誤りを支持するが、公式訂正ではない。別条件と一致する4fの2,200波形値は本来の内容を復元できず、そこを使う解析を制限した。

経験の随伴性によって更新先が切り替わる仮説も調べた。ただし、学習期EPG遮断の有無によるMBON更新差の3対比はいずれも区間が零を含んだ。異なる図の4独立群を使い、遺伝型・処置も完全には揃わない探索的比較である。完成した切替機構とは扱わない。[Rozenfeld & Parnas](https://doi.org/10.1126/sciadv.adq3016)

### 3. 動作名を、身体の部位と条件へ下ろす

旋回方向だけでは作用を記述しきれない。PFL3片側介入の刺激中の同側旋回速度は、PFL3群10個体と無opsin対照7個体の比較で平均+38.31°/秒だった。これは群間差であり、別の100試行表の刺激前後差+34.26°/秒とは異なる。刺激前後差は同じ試行の無刺激反実仮想ではない。[個体平均](../data/action/pfl3_intervention_fly_means.csv)

右中脚T2/Rの「開く」は、腿節–脛節を伸ばす作用と、脚の付け根の基節を外側・後方へ動かす作用に分けた。伸筋候補は`{830514,928579}`、外転・後方運動のPra候補は`{800776,803499,902719}`。番号はMaleCNS v1.0のbodyIdであり、別標本の同じ番号と結合しない。筋作用は前脚の筋地図と右中脚の型注釈を照合したもので、右中脚の新しい末梢実験ではない。928579のMANC個体番号は欠損を保った。[作用軸と拮抗筋](../data/structure/right_t2_axis_map.csv)、[筋地図の補足資料](https://faculty.washington.edu/tuthill/docs/azevedo24_appendix.pdf)

条件の影響は別型の公開介入でも見える。左前脚13Bの腿節–脛節の刺激−対照変位は、荷重あり−4.63°・7個体、なし−18.11°・4個体。9A-28981の脛節–跗節は、あり+4.27°、なし−0.70°・各6個体だった。13Bは刺激開始位置を確定できず、先頭60標本から末尾60標本への変位を用いた。荷重群を同一個体で対応させておらず、初期姿勢も統制していないため、荷重単独の因果効果とはしない。[Agrawalら](https://elifesciences.org/articles/60299)、[13B集計](../data/action/agrawal_13b_joint_response.csv)、[9A集計](../data/action/agrawal_9a_joint_response.csv)

### 4. 右中脚13Aの6候補で、確認済みの構造と不足する活動

六脚の運動ニューロン索引381個から右T2の58個を扱い、その全入力22,960辺・weight203,532を取得した。文献の前脚13A群と型対応する右T2の6候補は、i候補4個が屈筋側へ、ii候補2個が伸筋側へ偏る。型対応には801910の近似、MANC12790の対応欄重複などの留保がある。[Syedら](https://elifesciences.org/articles/106446)、[MaleCNS公式配布](https://male-cns.janelia.org/download/)

6候補間は23辺・weight893。i→iiは427、ii→iは446、群内は計20だった。近似候補801910を除いても群間463・群内20が残る。GABA性予測と文献の機能証拠は相反する筋への抑制配分という仮説を支えるが、対象辺の実効符号や右T2の因果効果は未測定である。[候補間接続と除外感度](../data/structure/six_candidate_internal_groups.csv)

6候補への全入力は4,592辺・weight39,310、感覚入力は4,498で、うち5は暫定分類を含む。直接感覚入力の割合は候補ごとに約1〜42%と異なる。同じ群でも800524は41.57%、800389は0.96%で、一律の二節点へ圧縮すると違いを落とす。[入力・出力を同版IDで結んだ6候補表](../data/right_t2_six_candidates.csv)

この表の感覚割合の分母は候補への全直接入力で、運動出力列は右T2の58運動ニューロン内の直接辺である。weightは解剖接続の集計値で、発火数、抑制力、筋力、関節角ではない。SNpp50/51の屈伸選択性もこの右T2標本では未同定である。

### 5. 活動変化、動作量、学習を取り違えない

別型13Bαの受動運動Caでは、3保存個体全てで伸展位>120°の平均ΔF/Fが屈曲位<60°より高く、個体内差は0.95456、0.83958、0.93124だった。過渡・角度履歴は未統制で、6候補の発火の代用にはならない。[角度対比](../data/activity/agrawal_13balpha_angle_summary.json)

物体操作課題では、旧配布表と公表統計の不一致を処理定義の差で再現した。その後の欠測感度では、未訓練群と前訓練群の原座標の点単位欠測が平均21.966%対0.265%と偏り、観測できた区間だけの近接割合は43.819%対43.789%になった。「経験で近寄る・全般に速くなる」という読み方は後退する。球移動の増加方向が残る感度もあるが、熟達、動機、力配分、結果予測のどれが変わったかは決められない。[Durrieuら、解析対象は第2版](https://doi.org/10.64898/2026.04.28.721021)

身体変化後の行動でも、平均同時動作数の増加と協調の指標は一致しなかった。Isakovの右前脚切断当日から3日後の同一個体比較では、CS株51個体で3脚同時動作割合+2.495百分率点・残存5脚の平均同時動作数+0.1975脚、iav株16個体では−1.947百分率点・+0.0124脚だった。これは配布の動作閾値による記述で、正常な三脚歩容、課題成功、結果随伴学習の証明ではない。[原データ](https://zenodo.org/records/51322)

6候補の活動を次へ結ぶには、対象型を確認した右T2で、初期関節角、荷重・支持、全脚状態、動作選択、結果履歴と活動を同期させる必要がある。受動屈伸、状態を合わせた自発運動、初見条件と反復、解除・再提示、結果随伴性の対照を分ければ、状態への応答と経験後の更新を比較できる。この観測仕様までが今回の到達点である。
