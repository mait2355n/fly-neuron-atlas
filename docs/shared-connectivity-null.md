# 接続数と群規模を保った共有接続の比較

2,155という共有候補数は、指定した166運動ニューロン・42筋群・辺weight≥10の定義による観測値である。接続先が多い細胞や構成細胞が多い群では、共有条件を満たしやすい。この説明と比べるため、条件を固定した接続組替えを追加した。

```sh
python scripts/shared_connectivity_null.py --replicates 32 --attempts-per-edge 10 \
  --seed 20260915 --output .local/shared-null-10
python scripts/shared_connectivity_null.py --replicates 32 --attempts-per-edge 30 \
  --seed 20261915 --output .local/shared-null-30
```

標準ライブラリだけで動く。入力は`data/motor_atlas.csv`、`data/motor_groups.csv`、`data/connectivity/motor_inputs.csv.gz`。出力は各試行の条件・入力ハッシュ・結果を含む`RUN.json`と、各上流細胞の`per_cell.csv`。指定出力先は新規または空であることを要求する。

`RUN.json.schema_version`は`fly-neuron-atlas-shared-null/v1`、`status`は`exploratory`。`trials`は反復結果の配列で、候補数・提案数・採用交換数を整数、`degree_invariants`を真偽値で保存する。正常終了時は要約JSONを標準出力へ出して終了符号0を返す。不正な引数は標準誤出力と終了符号2、入力や保存条件の破損による例外は標準誤出力と非0終了になる。終了符号0は計算完了を表す。

## 保存する条件

閾値を満たし、運動ニューロン以外の神経細胞から選択166細胞へ届く12,935辺を対象とする。元細胞は4,702。2辺(a→b, c→d)を選び、a→d, c→bへ交換する。重複辺になる提案や同一端点の提案は棄却し、その場に留まる試行も含めて固定回数を数える。

各反復終了後、元グラフと組替え後のグラフの各細胞の接続数を照合し、全辺数と重複の不在も検査する。一致時は`degree_invariants=true`を保存し、不一致時は結果を保存せず例外で終了する。筋群の所属と構成細胞数は変えない。群への共有は、異なる運動ニューロンの数ではなく異なる群の数で数える。

辺の重み、空間配置、細胞型の対応、解剖的に可能な接続制約は保存していない。この接続組替えは閾値後の二値グラフに対する一つの比較基準である。

## 保存した探索結果

|辺あたり試行数|反復|観測共有候補|組替え後の平均|最小〜最大|
|---|---|---|---|---|
|10|32|2,155|3,070.75|3,060〜3,085|
|30|32|2,155|3,072.4375|3,065〜3,082|

各結果は[10回条件](../data/reanalysis/shared-null-10/RUN.json)、[30回条件](../data/reanalysis/shared-null-30/RUN.json)にある。観測候補数はこの組替えの全反復より少なく、「共有候補数が多いから特別な協調回路である」という解釈を支持しなかった。

2条件で近い集計値が出ても、十分な混合や一様抽出を証明したことにはならない。反復は観測グラフから再開する乱数試行で、生物学的な独立標本ではない。`descriptive_upper_tail_fraction`は観測以上となった試行の比率であり、形式的な有意確率として使わない。細胞別の値にも多重比較の補正や機能の正解付けはない。

観測された接続が筋群内へまとまる可能性などを次に調べられるが、空間・型制約を含む別基準と照合する必要がある。共有接続の特徴と、生体内で協調を引き起こす因果的役割は分けて扱う。
