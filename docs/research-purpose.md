# 研究の目的と成果の位置付け

目指すのは、同じ経験が知覚・評価・思考・感想・発話・即応・行動へ継続して使われ、動き続ける環境で自ら試し、学び、次の追求を見いだす人工主体である。会話で得た情報が行動を変え、行動の結果が後の会話や判断を変える。活動や中断を跨いでも必要な経験を使い、考えたり話したりしている間にも必要な反応を間に合わせることを含む。

この目的は、単一模型や単一過程という実装の指定ではない。同じ経験が複数の働きへ因果的に使われ、その影響が継続することを指す。主観的意識や人間と同じ感情の存在を、初期の成功条件には含めない。

ハエ研究は、情報共有、状態保持、経験による更新、行動選択、即応の仕組みを調べる中間課題である。神経IDと結線の由来を保った構造を切り出して組み替える方式と、原理を抽象化した人工的方式を比較する。最終主体の全体を特定の生物構造に限定しない。

## 公開物から使えるもの

- [接続・身体作用の目録](findings-body-and-activity.md)：どの細胞からどの出力へ届くか、取得した分母と未取得を追う。
- [回路操作の工具](../circuits/README.md)：内部辺、切断境界、共有する細胞、人工複製、変更の由来を保った構成を作る。
- [経験と方位の解析](../research/2026-09-16/experience-and-heading.md)：現在状態を表す活動、対応変更を教える信号、変更の保存候補を分ける。
- [人工側の比較案](../research/2026-09-16/artificial-subject.md)：同じ経験が別の状況の行動と第二の読出しに役立つか、除去・交換の対照で検査する。

構造の保存に成功したこと、活動や係数が変わったこと、訓練課題が解けたことは、それぞれの範囲の成果として扱う。未知条件への有用な適用、既存能力の破損、期限内の即応、会話と行動を跨ぐ経験利用には別の検証が要る。生物側の局所介入を、そのまま人工主体全体の成立へ読み替えない。
