# 収録資料の照合と検査の補強

2026年9月15日の公開基線 `a1e90c5` を、[出所台帳](../data/provenance.json)に記載したローカル研究資料と照合した。37表すべてで元ファイルのSHA-256が一致した。列の選択、40細胞の抽出、出典参照の置換を考慮すると、公開表の保持値も一致した。これはその記録時点の資料との一致であり、原研究の解釈や生体機能を認定するものではない。

## 再計算脚本で修正したこと

旧 `reproduce.py` は、存在する行の値を比較していたが、必要な行が揃っていることを十分に検査していなかった。収録表から1行を除いた一時コピーで、次の3種類すべてが終了符号0・`pass`を返すことを確認した。

|欠落させたもの|修正後の検査|
|---|---|
|`studied_cells.csv` の調査細胞1行|全候補表で入出力取得済みとされた細胞の集合と、掲載行の全列を照合|
|`studied_totals.csv` の閾値別分母1行|各調査細胞×入力・出力×閾値1/3/5/10の各行を一度ずつ要求|
|`annotation_sensitivity.csv` の候補1行|全候補の細胞番号集合との一致を要求|

また、細胞番号が重複した表を辞書へ読み込む際に後の行で黙って上書きする処理を廃止し、明示的な失敗にした。

ハッシュ検査は、記録したファイルが変更されていないことを確かめる。今回補強した検査は、編集後にハッシュを更新しても、表の関係が壊れていれば再計算を失敗させる。両者を分けて使う。

## 検出を確認した範囲

[回帰試験](../tests/test_reproduction.py)は公開コマンドを一時コピー上で実行する。正常な収録資料が通ることに加え、上記3種類の欠落、分母行の重複、調査細胞の型注釈の書換え、候補細胞番号の重複を検出する。旧脚本では正常例だけが期待通りで、6つの不正例を検出できなかった。

研究資料の全原電位・H5・RDataを今回再実行したわけではない。原電位23記録に関する既存の照合証拠は[別記録](../data/ephys_validation.json)に残し、今回の表間整合性検査と区別する。新しい生理実験、未知候補の活動、科学的な最終受理も、この検査の対象ではない。
