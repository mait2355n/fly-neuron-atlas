# 欠測・表間整合性・再解析の修正記録

対象基線は `a1e90c5de104c9e747bfe8d50e1d9e19e09cbc1b`（v0.1.0）。2026年9月15日に、模擬入力で誤った合格判定を再現し、検出試験と実装を修正した。原研究16束と従来の37収録表は保持し、新しい数値は `data/reanalysis` に別版で保存する。

## 実装と検出試験

|指摘|修正と検出範囲|
|---|---|
|1 解析不能でも合格|処理完了と数値利用可能性を分離。期待チャンネル・比較系列・標本100以上・有限な必要相関を検査。全電圧欠測、全刺激ON、定数yawを除外し、片側だけ有効ならpartial。主集計採否も連動|
|2 刺激欠測が刺激なし|非有限な刺激を含む10ms区間を不明として除外。既知の刺激と同じ前100ms・後250msの影響範囲を各時計区間内で遮断|
|3 時計境界を跨ぐ検出|標準化の区間分割を維持し、ピーク突出度・発火率とVmの平滑化・不応期集計を区間独立に変更。時間移動対照と相関の標本対も境界を跨がない。境界1秒前の人工ピークで連結依存の解消を確認|
|4 同一辺の矛盾|共同観測範囲の辺集合とweight・weightHP・weightHRを照合。合計を保存する重み変更でも拒否|
|5 主キー・必要行・対象|分母の全組合せ、細胞台帳、チャンネル名・位置、相関対象yaw、主集計系列、重複主キーを検査。再解析wrapperもflyを含む行の所属を検査|
|6 再実行と参照の照合|独立した`compare_ephys.py`を追加。4基礎表の主キー、欠落・余剰、比較列、NaNと許容差を検査。小型MATを実際の再解析CLIへ渡すCIを追加|
|7 追補の生成コード|閾値・双側差・電位品質・時計境界・参照閾値の6表を生成する`reproduce_sensitivity.py`を追加。23件から再生成|
|8 文字コード|公開脚本の文字列入出力をUTF-8へ統一|
|9 中断ダウンロード|試行ごとに固有の一時ファイルを作成。失敗時はその試行のファイルを除去。古い`.part`や既存の完成ファイルを保存し、再試行を妨げない|

仕様とコマンドは[表の契約](table-contracts.md)、[結果比較](ephys-comparison.md)、[再解析](reproducing.md)、[追補生成](sensitivity.md)を参照。`record_complete`は必要な計算系列の存在、`analysis_complete`は全必要系列の数値利用可能性を表す。処理が終わっても、後者が偽なら再解析の総合判定は合格にならない。著者による低SNR除外も別に残す。

試験では、元版の全電圧欠測・全刺激欠測・全刺激ON・片側電圧欠測がいずれも終了符号0となることを、同じMATバイト列で確認した。現行版は前3者をexcluded、片側欠測をpartialとして終了符号1を返す。wrapperへの返却行だけを故障注入する試験では、同数の架空チャンネル、誤った相関対象、別flyへのすり替え、非有限相関、標本不足も拒否する。

試験群は[tests](../tests)にある。これらは検査能力と計算の境界に関する証拠であり、発火の生物学的正解付けや人間の最終受理を代替しない。

## 収録された全接続辺への影響

3表の全辺を走査した。主キー重複はなく、運動入力と調査細胞出力の共通2,352辺、調査細胞の入力と出力の共通234辺は、集合も3種の重みも一致した。運動入力と調査細胞入力の共同観測範囲は空であり、範囲外の接続をゼロとは判定しない。

収録表からの再集計値は従来値と一致する。815運動ニューロン、指定166細胞・42群に対する共有候補2,155、調査40細胞という構造集計値は変更していない。

## 原電位23記録への影響

Python 3.12.14、NumPy 2.3.5、SciPy 1.18.1、Matplotlib 3.11.2で、全23原MATのサイズ・MD5・SHA-256を確認して再実行した。23記録すべてに必要な数値結果が存在した。33チャンネル、30比較系列、6,363時間差相関行を[修正版の基礎結果](../data/reanalysis/epoch-v2/RUN.json)に保存する。著者LOW_SNRの`a2_d_14`は引き続き主集計から除外する。

[旧版との差分](../data/reanalysis/comparison-v1.json)は総合`fail`を保持する。これは異なる処理方式の結果が同一ではないことを示す。比較を合格させるために許容差を広げてはいない。全記録の理由文の変更を除く数値差は、時計リセットを含む`a1_a2_d_01`と`a1_a2_d_04`に限られた。

|対象|原方式 → 区間独立方式|
|---|---|
|`a1_a2_d_01`|基準発火数・基準相関は同じ。各時計区間内へ変更した時間移動対照が変化|
|`a1_a2_d_04` DNa02|推定発火40,070 → 40,069。yawの+150ms相関 −0.2988914301 → −0.2988934546|
|`a1_a2_d_04` DNa01|推定発火38,671 → 38,670。yawの+150ms相関は同じ|
|DNa02双側主3記録|発火数・全共通基礎相関・時間差曲線は従来値と一致|

主比較の`A_minus_B`とyawの+150ms相関は、`a2_d_08`が−0.3796658548、`a2_d_12`が−0.7119838534、`a2_d_13`が−0.2957955220。修正前後で同じである。最終wrapperで23件を再度計算し、同じ修正版coreによる先の全件計算へ独立比較器で照合した。[反復比較](../data/reanalysis/repeat-comparison.json)

従来の[data/ephys_validation.json](../data/ephys_validation.json)は、公開当初の方式とコードハッシュに対する履歴証拠である。現行方式の合格証として読み替えない。

## 頑健性の追試範囲

全23件から、閾値156行、対応する二系列の閾値50行、DNa02双側閾値24行、電位品質63行、時計境界24行、参照閾値33行を生成した。[実行記録と設定](../data/reanalysis/sensitivity-v2/SENSITIVITY.json)

DNa02主3記録の閾値倍率0.75・1・1.25・1.5・2・2.5では、差とyawの相関は全て負だった。その範囲はそれぞれ−0.3855〜−0.3026、−0.7120〜−0.4545、−0.3335〜−0.2652。Vm≤−33mVを両側に課すと−0.3373、−0.5935、−0.2869となった。これらは同じ個体内の感度分析で、新しい独立個体数には数えない。

指摘10の[標準化方式比較](normalization-sensitivity.md)では、同じ前処理・同じ閾値で連続局所窓MADへ変更する3記録の比較と固定波形例を追加した。方式による依存を調べる範囲であり、発火率や利得の模型較正を認定してはいない。

指摘11の[条件を保つ接続組替え](shared-connectivity-null.md)は、接続数と群規模を保った探索的な比較である。共有候補2,155を偶然以上の協調機能の証明へ進める根拠は、この比較では得られなかった。

## 保存基線と再利用

`data/activity`と元の[出所台帳](../data/provenance.json)は従来の記録として保存する。新規結果は[再解析出所台帳](../data/reanalysis/PROVENANCE.json)で入力・コマンド・コード・設定・出力を結ぶ。CIは保存表の検査と小型異常入力を実行し、5.51GBの原電位再解析は明示コマンドで実行する。

全16研究束の全追補、波形の人手正解付け、接続組替えの十分な混合、未知個体への一般化、協調機能の因果的介入は未検証として残る。
