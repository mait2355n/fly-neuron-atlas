# 経験更新・人工主体・回路再利用の研究記録

2026-09-16時点の四つの研究束から、公開資料の再解析結果、指標の反例、人工側の比較案、回路境界の所見をまとめた。目標は、同じ継続する経験が知覚・評価・思考・発話・即応・行動へ使われ、自ら試し学ぶ実時間の人工主体を作ること。局所的な方位課題の成功は、その主体全体の成立を意味しない。

|読む目的|入口|到達点|
|---|---|---|
|経験で方位表現がどう変わるか|[方位と経験更新](experience-and-heading.md)|公開加工記録・表示数表の再解析。角度近似、欠測、標本単位、負の結果を区別|
|差の指標に何が隠れるか|[14個体の二成分表](basnak_components.csv)、[機械可読要約](summary.json)|自己方位側の上昇と目印近似側の低下を別に保持。時間順序を捨てる反例を検査|
|生物から何を人工側へ移すか|[人工主体への翻訳](artificial-subject.md)|保持・現在の必要・感覚運動変換を分ける比較案。人工側の改善実証は未実施|
|実結線を部品として使えるか|[切出し・組替えの境界](recomposition-boundaries.md)|共有ID、切断する接続、未取得出力、動態の仮定を明示|
|出所と利用条件を確かめる|[PROVENANCE.json](PROVENANCE.json)|選択した元ファイルの相対識別名・SHA-256、変換、一次出典、配布範囲|

## 手元で確かめる

リポジトリの根元でPython 3.10以降を使う。追加依存・通信・認証は不要。

```sh
python research/2026-09-16/verify.py
```

JSONを標準出力へ返し、成功時は終了符号0、不一致時は終了符号1となる。収録ファイルのハッシュ、表の識別子・値域、14個体からの二成分平均と増減数、差の恒等式、人工側の正答数の算術、同じ集中度Rで逸脱時間が異なる合成反例を検査する。元の生理配列や保存模型を再実行するものではない。

## 再現できる範囲

|水準|この公開物で可能なこと|含まないもの|
|---|---|---|
|収録物の完全性|宣言済みSHA-256、表の型・範囲・参照の検査|配布元の全資料の完全性|
|選択表からの再集計|EPG二成分の14個体集計、差の内訳、増減個体数、合成反例|元蛍光からの位相再推定、再標本化区間の再生成|
|結果の出所の追跡|公開データの版、論文・図、元研究束のファイル識別名と摘要|公開物に含めない元研究束の取得・再構築|
|原解析・生物・人工側の再現|手法と未取得入力を各報告で明示|生画像前処理、全原系列再実行、新しい生体実験、人工主体の有効性試験|

原研究束は本公開版とは別の保存成果物で、来歴にある束名は公開リポジトリ内のパスではない。この公開物だけで実行できる検査と、過去の解析で得た結果を分ける。公開版の作成に伴う全原解析の独立再実行は行っていない。
